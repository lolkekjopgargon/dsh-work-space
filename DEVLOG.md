# Devlog: посты в Telegram и Discord

Вкладка **Devlog** превращает работу над проектом в готовые посты для соцсетей.
Пишете один раз — уходит в нужные каналы на нужном языке.

## Что умеет

- **Три типа поста**: девлог (что сделано), стрим (выхожу в эфир), анонс (новость).
- **Задачи под рукой**: три списка — «В работе», «Готовые», «Опубликованные».
  Клик по задаче заполняет пост: код, название, описание, статус и картинки из её постов.
- **Несколько картинок**: до 10 штук, с превью и удалением.
- **Markdown**: жирный, курсив, зачёркнутый, код, ссылки, списки, заголовки.
  Есть предпросмотр. В Telegram разметка конвертируется в HTML, в Discord уходит как есть.
- **Перевод через ИИ**: кнопка «Перевести» зовёт DeepSeek API и заполняет второй язык.
- **Шаблоны**: сохранить текущий пост и вставлять его снова.
- **История**: все отправленные посты с результатом по каждому каналу.

## Настройка каналов

Откройте Devlog → иконка шестерёнки (**Настройки**).

### Telegram

1. Создайте бота у `@BotFather` (`/newbot`), скопируйте токен.
2. Добавьте бота в группу или канал. Для канала — администратором с правом публикации.
3. Вставьте токен в поле **Telegram bot token**.
4. Добавьте каналы списком (см. пример ниже): `chat_id`, при необходимости `thread_id` темы.

**Где взять `chat_id`.** Напишите что-нибудь в чат, где есть бот, затем откройте
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":-100...}`.
Для форумных групп там же будет `message_thread_id` — это id темы.

**Права.** Если бот не видит сообщения в группе, в `@BotFather` выполните
`/setprivacy` → выберите бота → **Disable**.

### Discord

1. Настройки канала → **Интеграции** → **Вебхуки** → **Новый вебхук**.
2. Скопируйте URL вебхука.
3. Для ветки или форум-темы добавьте `thread_id`: включите режим разработчика,
   правый клик по ветке → «Копировать ID».

Один вебхук = один канал. Нужны разные каналы под языки или типы постов —
создайте несколько вебхуков.

### Пример списка каналов

В настройках есть поле **Импорт JSON** — вставьте массив и нажмите «Добавить из JSON»:

```json
[
  { "name": "Devlog RU", "platform": "telegram", "kind": "devlog", "lang": "ru", "chatId": "-1001234567890", "threadId": "2" },
  { "name": "News EN", "platform": "discord", "kind": "devlog", "lang": "en", "webhook": "https://discord.com/api/webhooks/..." }
]
```

Поля:

| Поле | Значение |
|---|---|
| `name` | подпись в интерфейсе |
| `platform` | `telegram` или `discord` |
| `kind` | `devlog`, `stream`, `announce` |
| `lang` | `ru`, `en` или `any` |
| `chatId` | id чата Telegram |
| `threadId` | id темы Telegram (если форум) |
| `webhook` | URL вебхука Discord |

## Перевод

В настройках укажите **DeepSeek API key** и **Язык перевода**. Ключ хранится
только в браузере (`localStorage`), никуда не отправляется, кроме `api.deepseek.com`.

## Markdown

```
**жирный**  *курсив*  ~~зачёркнутый~~  `код`
## Заголовок
- пункт списка
[ссылка](https://example.com)
```

Кнопки над полем ввода вставляют разметку вокруг выделенного текста.

> Telegram принимает только поддерживаемые теги, поэтому переносы строк уходят
> как есть, а разметка конвертируется в `b`, `i`, `s`, `code`, `pre`, `a`.

## Отправка

1. Выберите тип поста.
2. Возьмите задачу из списка или напишите текст вручную.
3. Отметьте каналы (плагин подставляет подходящие по типу и языку).
4. Нажмите **Опубликовать**.

Результат виден в истории: ✓ по каналам, которые приняли пост, и ✕ с текстом
ошибки для остальных.

Галочка **«Перенести в «Опубликованные»»** после успешной отправки переносит
задачу в третий список — чтобы не путаться, по каким задачам пост уже был.
Это только внутри Devlog: на доске задач статус не меняется.

## Безопасность

- Токен бота, ключ DeepSeek и вебхуки хранятся в браузере, в файлы проекта не пишутся.
- Не публикуйте скриншоты настроек с открытыми полями.
- Токен бота можно перевыпустить: `@BotFather` → `/revoke`.
- Вебхук Discord можно удалить и создать новый в настройках канала.

## Если не отправляется

| Симптом | Причина | Что делать |
|---|---|---|
| `no token` | не сохранён токен бота | вписать в настройках |
| `chat not found` | бот не в чате или нет прав | добавить бота, дать права |
| `can't parse entities` | в тексте сломана разметка | убрать незакрытые `**`, `*`, `~~` |
| `HTTP 404` у Discord | вебхук удалён | создать новый |
| Пост ушёл не в ту тему | неверный `threadId` | проверить id темы |
