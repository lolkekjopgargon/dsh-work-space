# Composer Actions

Плагин для DeepSeek Harness: четыре кнопки в поле ввода.

- **Memory** — собрать итог сессии и предложить, что записать в долгую память проекта. Ничего не пишется без подтверждения.
- **Compact** — сжать контекст, не начиная новый чат.
- **New** — новый чат с уже вписанным началом: прочитать правила проекта и файл задач, вспомнить, где остановились.
- **Commit** — попросить агента сделать коммит по текущей задаче: проверить `git status`, сообщение с кодом задачи и обновить `.workspace/commits.json`.

## Связь с Work Space

Если установлен плагин **Work Space**, кнопка Commit находит задачу по текущему чату и подставляет её код в промпт. Без него кнопка тоже работает: код берётся из заголовка чата.

## Установка

Скопируйте папку в проект и установите через менеджер плагинов DSH, указав путь к папке пакета.

Требуется DSH `>=0.2.0-rc.1 <0.3.0`.
