# Установка

## Короткое описание для GitHub

> Work Space для DeepSeek Harness: доска задач проекта, отдельный чат на каждую
> задачу и история коммитов прямо в интерфейсе. Плюс кнопки Memory, Compact, New
> и Commit в поле ввода. Скилл для агента ставится автоматически.

## Требования

- DeepSeek Harness `0.2.x` (проверено на `0.2.2-rc.1`)
- Windows, macOS или Linux — плагин кроссплатформенный

## Шаги

1. Скачайте репозиторий (кнопка **Code → Download ZIP**) и распакуйте.
2. Откройте DeepSeek Harness.
3. Перейдите в **Plugins** → **Add plugin** → установка из папки.
4. Укажите путь к папке `work-space/` и подтвердите установку.
5. Повторите то же для папки `composer-actions/`.
6. Обновите страницу Harness (`Ctrl+F5`).

После этого:

- в левой панели появится **Work Space**;
- в поле ввода — кнопки **Memory**, **Compact**, **New**, **Commit**;
- скилл `work-space-board` скопируется в `~/.dsh/skills/` автоматически
  (если такого скилла ещё нет).

## Первый запуск

1. Откройте **Work Space**.
2. Нажмите **«Создать проект»**, выберите папку — плагин создаст главный чат.
3. В главном чате обсудите задачи; агент предложит их списком.
4. Нажмите **«Импорт»** и выберите файл задач (`.workspace/tasks.json`).
5. Карточки появятся на доске. Кнопка **«Чат»** на карточке открывает отдельную
   тему по задаче.
6. Закончили работу — нажмите **Commit**. Агент сделает коммит и обновит
   `.workspace/commits.json`; вкладка «Коммиты» покажет историю.

7. Хотите постить прогресс в соцсети — откройте вкладку **Devlog**, нажмите
   шестерёнку и добавьте каналы: токен бота Telegram и/или вебхуки Discord.
   Подробная настройка — в [DEVLOG.md](DEVLOG.md).

> **Важно:** пока не сделан первый коммит, файла `.workspace/commits.json` нет —
> и вкладка «Коммиты» будет пустой. Плагин его не создаёт, файл пишет агент.
> Нажмите **Commit** один раз, и история появится.

## Девлог

Вкладка **Devlog** рассылает посты в Telegram и Discord: девлог по задаче, анонс
или стрим. Настройка каналов и токенов — [DEVLOG.md](DEVLOG.md).

## Если что-то не работает

- **Нет панели Work Space** — проверьте, что плагин включён в Plugins и страница
  перезагружена.
- **Не читается история коммитов** — убедитесь, что в корне проекта есть файл
  `.workspace/commits.json`, и нажмите «Обновить» на вкладке «Коммиты».
  Формат файла, команды для агента и разбор ошибок — в [COMMITS.md](COMMITS.md).
- **Commit не подставляет код задачи** — код берётся из названия чата; назовите
  чат в формате `КОД — Название`.

## Удаление

Отключите оба плагина в Plugins. Данные доски останутся в браузере, файлы
`.workspace/` — в проекте; удалите их вручную, если не нужны.
