# Work Space

Плагин для DeepSeek Harness: доска задач проекта и история коммитов в левой панели.

## Что умеет

- **Задачи** — четыре колонки (бэклог, в работе, готово, архив) плюс корзина. Перетаскивание карточек, статусы, блокеры, записи с датой и картинками.
- **Отдельный чат на задачу** — создаётся из карточки; если чат уже есть, доска переключит в него.
- **Главный чат проекта** — определяется автоматически: это чат, не привязанный ни к одной задаче.
- **Коммиты** — вкладка с историей: ветки дорожками, фильтры по автору, ветке и коду задачи, файлы с `+`/`−`, diff, копирование sha.
- **Откат** — кнопка «Восстановиться» открывает подтверждение и готовит промпт для агента на `git revert` (история не переписывается).
- **Два языка** — русский и английский, переключение в меню с планетой. Свой перевод можно вставить как JSON.

## Данные

Доска и история хранятся в браузере (`localStorage`, префикс `workspace.`), а история коммитов дополнительно читается из файла проекта:

```
.workspace/commits.json
```

Плагин перечитывает его раз в 5 секунд, пока открыта вкладка «Коммиты», и по кнопке «Обновить».

## Установка

Скопируйте папку в проект и установите через менеджер плагинов DSH, указав путь к папке пакета. Плагин работает без настройки.

Требуется DSH `>=0.2.0-rc.1 <0.3.0`.

## Ограничения

- Файлы пишет агент: сам плагин в браузере не запускает `git`.
- Данные доски живут в браузере профиля. Для переноса используйте «Экспорт» / «Импорт».
- Список задач и история коммитов — локальные для проекта.
