# Work Space for DeepSeek Harness

Два плагина для DSH, которые превращают работу с агентом в проектную: доска задач,
история коммитов и удобные кнопки в поле ввода.

## Что это и зачем

Чат с ИИ-агентом — это поток. Обсудили идею, поправили код, отвлеклись на другую
задачу — и через неделю уже не вспомнить, что где делали и почему решили именно так.
История тонет в сообщениях, а проект живёт в файлах и коммитах, которые никто не
связывает с разговорами.

**Work Space** закрывает этот разрыв. Он делает из переписки рабочее место:

- **Доска задач** — карточки с кодом, названием, описанием, статусом и постами.
  Статусы: бэклог, в работе, готово. Задачи импортируются файлом, который готовит агент.
- **Отдельный чат на задачу** — нажали «Чат» на карточке, открылась сессия, где
  говорите только про эту задачу. Ничего не смешивается, контекст не теряется.
- **История коммитов** — вкладка показывает ветку, изменения, файлы со знаками
  плюс и минус. Откат делается через `git revert`, а не жёстким сбросом, так что ничего
  не теряется.
- **Девлог** — собирает пост по задаче и публикует его в Telegram и Discord: с картинками,
  разметкой, вариантами на русском и английском. Один раз написали — разошлось по каналам.
- **Кнопки в поле ввода** — Memory, Compact, New, Commit, чтобы не набирать команды руками.

### Как это выглядит в работе

1. Открыли проект, нажали «Создать проект» — появился главный чат.
2. Обсудили с агентом, что делаем. Он предложил список задач.
3. Импортировали список — карточки легли на доску.
4. Взяли задачу в работу: у неё свой чат, агент знает контекст только по ней.
5. Закончили — коммит. Вкладка «Коммиты» показывает, что изменилось.
6. Собрали девлог-пост и отправили в соцсети.

### Кому пригодится

- Соло-разработчику, который ведёт проект с агентом и хочет порядка без отдельного
  трекера: доска, коммиты и девлог живут прямо в DSH.
- Небольшой команде, где важно, кто чем занят и какие задачи уже закрыты.
- Тем, кто пишет о разработке: девлог превращает работу в посты без ручной возни.
- Проектам на Godot, в веб-разработке и вообще любым, где есть git.

### Кому не нужно

- Если вы просто спрашиваете у агента разовые вопросы — доска будет лишней.
- Если нужен полноценный трекер с несколькими пользователями, спринтами и отчётами —
  это не он. Здесь один проект и локальные данные.

### Что важно понимать

- Плагин **не заменяет git** и не коммитит сам: коммит делает агент по вашей просьбе
  или по кнопке, а плагин показывает результат.
- Данные доски хранятся **локально в браузере**, файлы проекта — в `.workspace/`
  в папке проекта. Никакого сервера и аккаунтов.
- Токены Telegram, ключ DeepSeek и вебхуки Discord хранятся только в браузере.
- Работает на Windows, macOS и Linux — это клиентский плагин DSH.

## Что внутри

| Папка | Плагин | Что делает |
|---|---|---|
| `work-space/` | **Work Space** | Доска задач проекта, отдельный чат на задачу, вкладка «Коммиты» с историей и безопасным откатом |
| `composer-actions/` | **Composer Actions** | Кнопки в поле ввода: Memory, Compact, New, Commit |
| `skills/work-space-board/` | скилл агента | Как вести доску и оформлять коммиты |
| [`COMMITS.md`](COMMITS.md) | гайд | Где лежит `commits.json`, его формат, команды для агента и разбор ошибок |
| [`DEVLOG.md`](DEVLOG.md) | гайд | Как настроить каналы Telegram и Discord, перевод и отправку постов |

Скилл устанавливается автоматически при установке Work Space: хост-часть плагина
копирует его в `~/.dsh/skills/work-space-board/`, если такого файла ещё нет.
Существующий скилл не перезаписывается.

## Установка

1. Установите оба плагина через менеджер плагинов DSH, указывая путь к папкам
   `work-space/` и `composer-actions/`.
2. Перезагрузите страницу.

Требуется DSH `>=0.2.0-rc.1 <0.3.0`.

## Как пользоваться

1. Откройте панель **Work Space**.
2. Нажмите **«Создать проект»**, выберите папку — плагин создаст главный чат.
3. В главном чате обсудите проект и задачи; агент предложит список.
4. Нажмите **«Импорт»** и выберите файл задач — карточки появятся на доске.
5. У каждой карточки есть кнопка **«Чат»**: она создаёт отдельный чат по задаче
   или возвращает в уже созданный.
6. Закончили — нажмите **Commit** в поле ввода. Агент сделает коммит и обновит
   `.workspace/commits.json`, а вкладка «Коммиты» покажет историю.

## Девлог

Отдельная вкладка рядом с задачами и коммитами: собирает пост по задаче и
рассылает его в Telegram и Discord.

- три типа поста: девлог, стрим, анонс;
- списки задач «В работе», «Готовые», «Опубликованные»;
- несколько картинок, Markdown с предпросмотром;
- перевод на выбранный язык через DeepSeek API;
- шаблоны постов и история отправок.

Настройка каналов, токенов и разбор ошибок — в [`DEVLOG.md`](DEVLOG.md).

## Формат файла задач

```json
{
  "prefix": "PRJ",
  "next": 3,
  "board": [
    {
      "id": "first-task",
      "code": "PRJ-1",
      "title": "Название",
      "note": "Короткая строка для карточки",
      "desc": "Что нужно сделать",
      "how": "Как это делать"
    }
  ]
}
```

## История коммитов

Плагин не запускает `git` сам. Он читает файл, который готовит агент:

```
<проект>/
  .workspace/
    commits.json
```

- пока открыта вкладка «Коммиты», файл перечитывается **раз в 5 секунд**;
- кнопка **«Обновить»** читает его сразу;
- кнопка **«Импорт»** принимает тот же JSON через выбор файла.

Файла нет, пока не сделан **первый коммит**: плагин его не создаёт, файл пишет
агент (кнопка **Commit**). До этого вкладка «Коммиты» будет пустой — это нормально.

Формат, все поля, готовые команды для агента, поиск ошибок и рекомендации —
в отдельной странице: **[COMMITS.md](COMMITS.md)**.

## Ограничения

- Плагин не запускает `git`: коммиты и файл истории готовит агент.
- Данные доски хранятся в браузере (`localStorage`, префикс `workspace.`).
  Для переноса — «Экспорт» / «Импорт».
- Откат делается через `git revert`, история не переписывается.
