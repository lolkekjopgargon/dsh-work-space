# Work Space for DeepSeek Harness

Два плагина для DSH, которые превращают работу с агентом в проектную: доска задач,
история коммитов и удобные кнопки в поле ввода.

## Что внутри

| Папка | Плагин | Что делает |
|---|---|---|
| `work-space/` | **Work Space** | Доска задач проекта, отдельный чат на задачу, вкладка «Коммиты» с историей и безопасным откатом |
| `composer-actions/` | **Composer Actions** | Кнопки в поле ввода: Memory, Compact, New, Commit |
| `skills/work-space-board/` | скилл агента | Как вести доску и оформлять коммиты |
| [`COMMITS.md`](COMMITS.md) | гайд | Где лежит `commits.json`, его формат, команды для агента и разбор ошибок |

Скилл устанавливается автоматически при установке Work Space: хост-часть плагина
копирует его в `~/.dsh/skills/work-space-board/`, если такого файла ещё нет.
Существующий скилл не перезаписывается.

## Установка

1. Установите оба плагина через менеджер плагинов DSH, указывая путь к папкам
   `work-space/` и `composer-actions/`.
2. Перезагрузите страницу.

Требуется DSH `>=0.2.0-rc.1 <0.3.0`.

## Как пользоваться

1. Откройте панель **Work Space**.
2. Нажмите **«Создать проект»**, выберите папку — плагин создаст главный чат.
3. В главном чате обсудите проект и задачи; агент предложит список.
4. Нажмите **«Импорт»** и выберите файл задач — карточки появятся на доске.
5. У каждой карточки есть кнопка **«Чат»**: она создаёт отдельный чат по задаче
   или возвращает в уже созданный.
6. Закончили — нажмите **Commit** в поле ввода. Агент сделает коммит и обновит
   `.workspace/commits.json`, а вкладка «Коммиты» покажет историю.

## Формат файла задач

```json
{
  "prefix": "PRJ",
  "next": 3,
  "board": [
    {
      "id": "first-task",
      "code": "PRJ-1",
      "title": "Название",
      "note": "Короткая строка для карточки",
      "desc": "Что нужно сделать",
      "how": "Как это делать"
    }
  ]
}
```

## История коммитов

Плагин не запускает `git` сам. Он читает файл, который готовит агент:

```
<проект>/
  .workspace/
    commits.json
```

- пока открыта вкладка «Коммиты», файл перечитывается **раз в 5 секунд**;
- кнопка **«Обновить»** читает его сразу;
- кнопка **«Импорт»** принимает тот же JSON через выбор файла.

Файла нет, пока не сделан **первый коммит**: плагин его не создаёт, файл пишет
агент (кнопка **Commit**). До этого вкладка «Коммиты» будет пустой — это нормально.

Формат, все поля, готовые команды для агента, поиск ошибок и рекомендации —
в отдельной странице: **[COMMITS.md](COMMITS.md)**.

## Ограничения

- Плагин не запускает `git`: коммиты и файл истории готовит агент.
- Данные доски хранятся в браузере (`localStorage`, префикс `workspace.`).
  Для переноса — «Экспорт» / «Импорт».
- Откат делается через `git revert`, история не переписывается.
